# Test-environment demo audio

Thirty AI-generated Gemini voice recordings of the fixed test message. These
assets are generated once, stored in PostgreSQL at startup, and reused for test
TTS requests. Every request still uploads to its paired Briefcase test environment.

`manifest.json` records the model, voice, exact source text, content hash, duration,
and Deepgram transcription check. Cross-provider matching has not been auditioned.
